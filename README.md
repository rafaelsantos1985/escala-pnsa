# ⛪ Sistema de Escalas Litúrgicas & Comunitárias
### Paróquia Nossa Senhora Aparecida — Cidade Industrial, Lorena/SP

Aplicação web moderna (PWA) e inteligente para gestão, distribuição equitativa e visualização das escalas de Ministros Extraordinários da Sagrada Comunhão (MESC).

---

## ✨ Funcionalidades

- **Gestão de Ministros**: Cadastro completo, controle de contingente ativo/inativo e marcação de preferências/disponibilidades.
- **Geração Inteligente de Escalas**:
  - Distribuição com equilíbrio de gênero e paridade.
  - Regra de fila circular para evitar sobrecarga.
  - Opção para marcar **dias sem missa** específicos no mês.
- **Visualização Flexível**:
  - **Quadro do Mês**: Visão completa estilo calendário mensal.
  - **Cartões**: Organização visual dia a dia, com cards responsivos.
  - **Lista / Tabela**: Visão tabular para conferência rápida.
- **Exportação & Comunicação**: Cópia formatada direta para WhatsApp e grupos comunitários.
- **Sincronização em Nuvem**: Integração com **Google Cloud Firestore** para atualização em tempo real entre dispositivos.
- **Suporte a PWA (Progressive Web App)**: Pode ser instalado diretamente na tela inicial do celular (Android e iOS) funcionando em tela cheia como aplicativo nativo.

---

## 🛠️ Tecnologias Utilizadas

- **Frontend**: HTML5 Semântico, CSS3 Moderno (Variáveis, Flexbox/Grid, Dark/Light theme), JavaScript ES6+ (Vanilla)
- **Banco de Dados**: Google Cloud Firestore (Firebase SDK v10)
- **Hospedagem**: Firebase Hosting
